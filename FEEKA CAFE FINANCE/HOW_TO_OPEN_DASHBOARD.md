## ❓ TROUBLESHOOTING

### **File won't open?**
- Make sure it's a `.html` file (not .txt)
- Try right-click → "Open With" → Choose your browser

### **Blank page?**
- Wait a few seconds for it to load
- Refresh the page (⌘R on Mac)
- Try a different browser

### **Data not saving?**
- Check if browser allows local storage
- Try incognito/private mode first
